接続設定

ローカルモード：このPCの gh の認証を使います。トークンは不要です。

タスクは GitHub のリポジトリに保存されています。このブラウザから読み書きするために、アクセストークンを一度だけ設定してください（このブラウザ内にだけ保存されます）。

  1. Fine-grained token の作成ページを開く
  2. Repository access →「Only select repositories」で pkb だけを選ぶ
  3. Permissions → Repository permissions →「Contents」を Read and write
  4. 作成されたトークンを下に貼り付け
